Core principles
Borders are 0.5px
Never 1px. Thin strokes feel native and refined. Use tertiary opacity for resting state, secondary on hover.
No shadows on surfaces
Elevation is communicated via background color difference, not drop shadows. Modals use an overlay + border.
Density over padding
Rows are 32–36px, not 48px+. Users see more data. Use 4px vertical padding in list rows.
Keyboard-first interaction
Every action has a shortcut. Show them in tooltips and command palette. Focus states must be clearly visible.
Monochrome with semantic color
UI is near-neutral. Color is reserved for status (info/success/warning/danger) and entity type dots.
Transitions: 120–150ms
Hover states use 100ms ease. Slide-in panels use 150ms ease-out. Avoid bouncy or spring animations.
